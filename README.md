# Airbnb Simulator

Petit simulateur front-end pour évaluer un deal d'arbitrage locatif.

## Ouvrir l'application

Double-clique sur `index.html` pour l'ouvrir dans ton navigateur.

## Ce que calcule l'outil

- chiffre d'affaires mensuel estimé
- bénéfice net mensuel
- marge nette
- ROI annuel sur cash investi
- seuil de rentabilité en taux d'occupation
- score global du deal sur 100

## Conseil d'usage

Teste plusieurs scénarios avec:

- un prix moyen par nuit plus prudent
- une occupation plus conservative
- des charges un peu plus élevées que prévu

Si le deal reste bon dans un scénario prudent, il est souvent bien plus robuste.
